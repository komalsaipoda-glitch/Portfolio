# KOMAL SAI — Portfolio Clone

A React + Vite recreation of the supplied Spydyy portfolio reference, customized for Komal Sai.

## Reference / visual direction
The layout, hero mask interaction, red Spider-Man visual language, marquee treatment, section rhythm, typography scale, cards, and GSAP motion are based on the supplied reference site and original source ZIP.

- Education: 72% ZPHS, 77% Intermediate, 8.7 CGPA B.Tech

## Responsive photos
The first two hero photographs use compressed desktop and mobile WebP variants so the composition fits Windows/laptop and phone viewports without unnecessarily large files. The third photograph is also compressed as `profile.webp` and fitted into the reference circular profile frame.

## Run
```bash
npm install
npm run dev
```

Production:
```bash
npm run build
npm run preview
```

No `node_modules` directory is included in the ZIP.
